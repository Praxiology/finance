# 第五部分：为什么有些国家能够工业化，有些国家却长期无法完成转型？

这一部分要研究一个关键问题：为什么引进了机器、资本和技术，并不意味着一个国家就能实现工业化？

这个问题直接连接英国工业革命、德国和美国的后发追赶、日本的明治维新、苏联的重工业化、中国的改革开放，以及许多发展中国家的工业化困境。

先给出核心判断：

工业化不是把机器搬进一个农业社会，而是把整个社会改造成一个能够持续创造、扩散和迭代生产力的系统。

机器只是生产工具。真正的工业化还要求能源、交通、熟练劳动力、企业组织、供应链、金融体系、市场需求、技术学习和国家协调能力形成互补。

## 一、先区分三个经常被混淆的概念

第一层：拥有工业设备

购买机器、建设工厂、引进外国技术、进口生产线。

这意味着具备了某些生产工具，但不代表能独立维护、改进设备，也不代表本土企业能持续盈利。

第二层：形成工业体系

能够生产零部件、材料、能源、设备，培养工程师，并组织上下游企业协作。

工厂不再是孤立的生产岛，而是嵌入国内供应链、技术体系和市场体系。

第三层：形成持续的工业化能力

能够不断提高生产率，开发新产品，改进工艺，培育新产业，并将创新成果扩散到整个经济。

这才是工业化真正的深层目标：不只是生产工业品，而是建立持续升级生产力的机制。

例如，一个国家可以进口一整条汽车生产线，但如果关键材料、精密设备、工艺工程师、质量管理和供应商体系都依赖国外，它可能具备汽车组装能力，却尚未建立完整的汽车工业能力。

反过来，一个国家即使最初不掌握最先进的技术，只要能够持续学习、改进、扩大生产规模，并培养本土供应链，也可能逐步完成工业化。

因此，研究的核心不是“有没有机器”，而是：一个国家有没有能力把外部技术转化为本土持续增长的生产率。

## 二、工业化真正依赖的六个底层条件

这六个条件不是简单的并列清单，而是一个相互依赖的系统。某个环节长期缺失，就可能成为整个工业化进程的瓶颈。

1\. 农业剩余与劳动力释放

让更多人能够离开低生产率农业部门

2\. 能源、交通与基础设施

让工厂能够低成本、稳定地生产和运输

3\. 技术吸收与工程技能

把机器转化为实际产出，并持续改进工艺

4\. 企业组织与产业集群

把分散的劳动、资本、设备和知识组织起来

5\. 市场、融资与规模经济

让企业能够扩大规模、回收投资、继续创新

6\. 持续的技术升级与生产率增长

从模仿、组装走向工艺改进、核心零部件和自主创新

需要特别注意：这不是严格的单向时间顺序。工业化也会反过来促进农业机械化、扩大市场、培养技能，并创造新的基础设施需求。

### 条件一：农业必须释放足够的社会剩余

为什么工业化不能只靠建工厂？

因为工业工人需要吃饭，工厂需要原材料，城市需要供水、住房和交通。农业部门必须提供足够的粮食和其他资源，才能支撑非农业人口扩张。

假设一个国家有 1000 万劳动力：

- 700 万人从事农业，平均每人每年生产 1 单位粮食。
- 通过农业技术、灌溉、肥料和组织改进，人均农业产出提高到 2 单位。
- 在粮食需求不变的简化假设下，农业可能用更少的劳动力满足原有需求，释放出的劳动力便有机会进入制造业和服务业。

这里的关键不是简单地把农民赶进工厂，而是农业劳动生产率提高，使社会能够用更少的劳动生产同样多甚至更多的食物。

如果农业生产率长期停滞，工业化可能面临粮食价格上涨、城市工资成本增加、劳动力难以转移等约束。

这也解释了为什么历史上的工业化往往伴随农业生产率提升，而不只是制造业产值上升。

### 条件二：能源和交通必须改变生产的成本结构

工业革命的关键不只是出现了蒸汽机，而是机器能够在特定的能源、工资和市场条件下带来经济收益。

经济史学家 Robert C. Allen 提出，18 世纪英国较高的工资和相对廉价的能源，使节省劳动力的机器更有经济吸引力。

可以把企业是否采用机器简化为：

\\[ \text{机器的净收益} = \text{节省的劳动成本} - \text{资本与能源成本} - \text{维护及其他成本} \\]

如果机器节省的工资不足以覆盖机器、能源、维护和融资成本，企业就可能没有动力采用它。

但这并不意味着英国工业革命完全由工资和煤炭决定。机械技能、科学知识、市场规模、贸易、制度和企业家的试错同样重要。相关经济史研究对于各因素的相对权重仍有争论。

交通则改变另一组成本：

- 铁路降低煤炭、铁矿、粮食和制成品的运输成本。
- 港口让企业接入更大的国内外市场。
- 稳定的电力网络降低工厂停机风险。
- 通信网络降低企业之间的协调成本。

因此，能源和交通不是工业化之外的辅助设施，而是决定工业生产是否具有经济可行性的组成部分。

### 条件三：会操作机器，不等于会改进技术

这是技术追赶中最容易被低估的一环。

一台机器的有效生产能力，至少取决于三个层次：

| 层次    | 能力表现             | 主要瓶颈           |
| ----- | ---------------- | -------------- |
| 操作    | 按说明书生产           | 工人培训、操作规范      |
| 维护与适配 | 排除故障、调整参数、适应本地原料 | 技师、备件、工艺知识     |
| 改进与创新 | 提高良率、降低成本、重新设计工艺 | 工程体系、研发能力、试错机制 |

假设两家企业购买了同一型号的纺织设备。

A 企业只会按照说明书操作；B 企业能够调整设备参数、改进工序衔接、降低断纱率，并根据原料变化优化工艺。

即使两家企业的设备相同，B 企业的单位成本也可能随着生产经验积累而持续下降。

英国工业革命的一个重要基础，正是能够将新发明落地的机械工匠、技师和工程人员。Meisenzahl 与 Mokyr 对英国机械师和工程师的研究，强调了学徒训练、技能供给以及创新激励的作用。

这就引出一个重要概念：吸收能力（absorptive capacity）。

它指一个组织或国家识别、理解、吸收和应用外部知识的能力。技术可以购买，但吸收能力必须通过教育、生产实践、组织学习和研发逐步积累。

### 条件四：必须从孤立工厂发展出产业体系

一座工厂的生产效率，与一个工业体系的生产效率，不是同一回事。

设想某国建立了一家汽车组装厂，但以下环节都依赖进口：

- 发动机、变速器和精密轴承；
- 特种钢材、电子元件和工业软件；
- 高精度加工设备与检测仪器；
- 设备维修、工艺设计和质量控制服务。

这家工厂可以生产汽车，却可能缺少持续降低成本、迭代产品和应对供应中断的能力。

产业体系成熟后，情况会不同：

1. 零部件供应商能够围绕整车厂持续改进产品。
2. 材料企业可以根据加工需求调整材料性能。
3. 设备企业能够针对生产问题开发专用设备。
4. 高校、职业教育和企业共同培养技术人员。
5. 大量企业在共同生产中积累工艺知识，并将其传播到上下游。

这些联系会形成产业集群与知识溢出：企业的学习不再完全依靠自身研发，也可以来自供应商、客户、竞争者和工程人员流动。

因此，产业链的价值不仅是提高国产化率，更是让一个国家拥有持续解决生产问题的组织网络。

### 条件五：企业需要市场和融资，才能跨过规模门槛

许多工业项目存在较高的固定成本。

假设一家工厂的年固定成本为 1000 万元，每件产品扣除单位变动成本后的贡献为 100 元，那么：

\\[ Q\_{\text{盈亏平衡}} =\frac{1000\text{万元}}{100\text{元/件}} =10\text{万件} \\]

如果市场一年只能吸收 2 万件产品，企业就很难仅凭本地需求实现盈亏平衡。

这会产生工业化的协调难题：

- 没有大市场，企业不愿意投资大规模工厂。
- 没有工厂，供应商和技术人员不愿意进入。
- 没有供应商和技能，生产成本又降不下来。
- 成本降不下来，产品便难以打开更大市场。

突破这一循环的方式可能包括国内市场整合、出口、基础设施投资、产业集群发展，以及有条件的政策支持。

融资同样关键：大型设备、铁路、电力和基础材料项目需要先投入大量资本，收益却可能多年后才能实现。金融体系若无法提供期限匹配的资金，社会即使有储蓄，也未必能将其转化为长期工业投资。

### 条件六：必须形成持续升级的机制

工业化的终点不是把某个行业做大，而是能够不断进入更复杂、更高生产率的活动。

典型路径可能是：

初级加工

劳动密集型产品、简单组装

规模制造

标准化生产、质量控制、成本优化

零部件与设备

关键零部件、工业母机、自动化系统

工艺与产品创新

自主设计、材料研发、生产流程创新

技术前沿

研发平台、核心技术、持续创造新产业

这不是每个国家都必须严格经过的固定路线。后发国家可以跳过某些技术阶段，直接采用先进设备或数字技术。但如果缺少工程人才、供应链和持续学习能力，跳过的环节也可能成为后续发展的约束。

明治维新后，日本积极引进西方设备、技术人员和生产组织方式。但日本的工业化不能简单概括为“政府买来机器，国家就现代化了”。

更重要的是技术吸收过程逐步升级：

| 阶段   | 日本的能力变化                   |
| ---- | ------------------------- |
| 引进   | 聘请外国专家、购买设备、学习技术资料        |
| 操作   | 培养本土技术人员，使工厂稳定运行          |
| 适配   | 根据本国原料、劳动条件和市场调整生产工艺      |
| 改进   | 仿制和改进设备，培养工程师与企业管理人员      |
| 自主发展 | 扩大研发、建立本土企业体系，并逐步掌握更先进的技术 |

日本的追赶还建立在明治维新之前已有的商业活动、手工业技能和地方经济发展之上。研究日本工业化的学者特别强调，既有的国内经济基础为吸收西方技术提供了条件。

这揭示了一个重要规律：

外部技术转移的效果，取决于接收方能否将技术嵌入自己的技能、企业、供应链和市场体系。

### 案例三：韩国——为什么出口竞争和产业政策能够相互配合？

韩国战后的工业化展示了另一种机制：政府不仅支持企业发展，还通过出口市场检验企业是否真正具备竞争力。

其发展过程涉及出口促进、定向信贷、基础设施建设、技术引进以及企业组织能力的积累。相关研究认为，韩国有选择的产业政策对部分产业形成国际竞争力作出了重要贡献，但政策的净效果和反事实仍有学术争论。

[image](https://www.google.com/s2/favicons?domain=https://www.aeaweb.org\&sz=32)

可以把这种模式理解为一套反馈机制：

政府提供融资、基础设施与产业支持

企业引进技术、扩大生产、培养人才

进入国际市场，接受价格、质量和交付能力的检验

根据竞争结果继续投资、改进，或淘汰低效生产方式

出口市场的意义不只是带来外汇。

它还提供了一套相对严格的外部检验：产品是否达到国际质量标准，成本是否足够低，交货是否可靠，技术能否持续升级。

但这套机制有前提。企业需要有学习机会，政府需要能够识别支持效果，也需要具备削减失败项目支持的能力。如果补贴长期与业绩脱钩，产业政策就可能从能力建设变成寻租。

2024 年一项关于韩国 20 世纪 70 年代工业化的研究，发现现代技术采用存在协调失败：企业采用技术的收益不仅取决于自身，也取决于周围企业是否采用；针对技术采用的补贴能够影响企业行为并产生本地溢出效应。

这里还需要区分一个关键概念：制造业占比下降，不等于工业能力一定下降。

两者表面上都叫“去工业化”，背后的经济机制却可能完全不同。

## 五、由此推导出一个更深层的规律：工业化存在协调失败和路径依赖

为什么市场有时不能自动把一个国家带入工业化？

因为产业发展往往存在互补性。

一家企业投资新设备，收益取决于电力、供应商、技术人员、物流和市场是否同时到位。如果其他环节都没有发展，它的投资可能亏损；但如果许多企业和基础设施同步发展，整体收益就可能明显增加。

这被称为协调失败（coordination failure），也是“大推进”（Big Push）理论关注的核心问题之一。韩国的技术采用研究为这类机制提供了具体的历史证据，但不意味着所有产业都需要大规模同步投资。

+1



可以用一个简化模型表达：

\\[ \text{企业投资收益} = \text{自身效率提升} + \text{产业网络带来的额外收益} - \text{投资成本} \\]

其中，产业网络带来的收益可能来自供应商改进、熟练工人流动、共同基础设施和市场扩大。

当产业网络尚未形成时，企业可能不愿投资；当投资达到一定规模后，互补收益又可能使工业化加速。

这就解释了为什么有些经济体的工业化表现为长期缓慢积累，随后出现快速扩张，而不是每年匀速增长。

不过，这种机制也有反面：如果政府错误选择产业、过度补贴或长期保护低效率企业，协调失败可能被错误的政策固化。国家协调能力必须与信息获取、绩效评估和退出机制结合。

## 六、把国家能力、工业化和长期增长统一起来

前面几部分讨论了国家形成、财政能力、战争动员，以及国家能力如何影响经济增长。现在可以把工业化放进同一张因果图中。

国家能力与制度安排

税收、司法、基础设施、教育、公共协调

工业化的互补条件

能源、技能、资本、供应链、市场、技术吸收

产业扩张与劳动生产率提高

规模经济、工艺改进、资源重新配置、知识扩散

收入、税基与技术能力提升

为下一轮教育、研发、基础设施和产业升级提供条件

正向反馈：生产率提升可以扩大下一轮发展能力

这个系统存在两种可能的反馈方向。

- \*\*正向反馈：\*\*生产率提高 → 收入和税基扩大 → 基础设施、技能与研发投入增加 → 企业能力增强 → 生产率进一步提高。
- \*\*负向反馈：\*\*生产率低 → 税基弱、融资贵 → 基础设施与技能投资不足 → 企业竞争力弱 → 难以扩大市场和积累技术。

这两种反馈都不是必然结局。国际贸易、外部技术、政治改革、战争、金融危机、人口结构和全球产业分工，都可能改变发展路径。

### 一个必须纠正的误解

不能简单得出“国家越强，工业化就越成功”的结论。

国家可以把资源用于公共基础设施、教育、技术研发和产业协调，也可以将资源用于保护既得利益、维持低效率企业和强化寻租。

所以真正需要考察的不是国家规模本身，而是：

1. 国家能否识别真实的生产瓶颈？
2. 能否提供私人部门难以独立建设的互补条件？
3. 能否让企业接受市场、出口和生产率的检验？
4. 能否根据结果调整或终止失败政策？
5. 能否让工业化成果转化为更广泛的生产率提升，而不是只集中于少数企业或部门？

世界银行近期的产业政策框架也强调，政策支持需要与证据、绩效和退出机制结合；过早终止可能损害学习收益，长期支持失败项目同样会造成浪费。

## 七、本部分最终提炼：工业化的底层逻辑

把上述机制压缩成一个判断框架：

\\[ \boxed{ \text{持续工业化} = \text{技术吸收} \times \text{互补条件} \times \text{组织学习} \times \text{市场检验} } \\]

这里使用乘法是为了强调互补性，而不是声称存在一个可直接用于统计的精确公式：如果其中某个关键因素接近于零，其他因素的投入就可能无法充分转化为持续的工业化能力。

- 只有技术，没有吸收能力，设备可能变成孤岛。
- 只有资本，没有市场和组织能力，投资可能无法回收。
- 只有市场，没有基础设施和产业互补，企业可能长期停留在低附加值环节。
- 只有国家支持，没有绩效约束，产业政策可能变成寻租。
- 只有初期制造业扩张，没有持续学习，就可能在竞争加剧后失去优势。

最核心的结论是：工业化的本质不是资本和机器的简单积累，而是一个社会持续学习、组织生产、扩展市场并提高生产率的能力形成过程。

从这个角度看，工业革命不是一次性的机器革命，而是生产组织、技术知识、能源利用和社会制度共同发生变化的历史过程。

下一步最值得研究的是：为什么工业化曾经主要通过制造业实现，而今天一些发展中国家却在尚未达到高收入水平时就出现制造业就业占比下降？这是否意味着传统工业化道路正在改变？

这将把历史上的工业革命与当代的全球产业分工、自动化、人工智能和“提前去工业化”问题连接起来。
