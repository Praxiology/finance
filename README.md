# 从零建立金融学知识体系

本工程以通俗、递进、可检验的方式学习经济学与金融学：从资源约束和选择开始，逐步连接货币、信用、资产定价、宏观周期、国际金融与经济思想史。目标是建立能够独立分析问题的知识体系，不承诺通过阅读文档即可替代系统训练、专业资格或实际经验。

## 学习入口

- [全局推进计划](全局学习计划.md)：课程结构、批次目标、文档规范与质量标准。
- [学习进度与续学记录](学习进度.md)：当前进度、下一步和可直接使用的续学指令。
- [第 001 课：稀缺性](课程/第001课-稀缺性.md)：首课正式讲义。
- [基础理论与 120 课路线](基础理论.md)：现有课程编号及每课核心问题，是课程顺序的参考底稿。
- [20 个元概念索引](元概念.md)：跨课程的底层概念关系，不是另一套并行课表。
- [稀缺性旧稿](稀缺的.md)：保留的素材草稿；阅读时以正式讲义为准。

## 如何继续

从 [学习进度与续学记录](学习进度.md) 中的“下一步”开始。每完成一课或一批，就更新进度记录；不要仅凭对话上下文判断学到哪里。建议按课程编号推进，也可以提出某个概念编号要求补课、复习或交叉分析。
