# 第二部分：国家能力的财政基础——为什么有些国家富而强，有些国家富而弱？

我们从一个看似矛盾的现象开始：

- 有些国家自然资源丰富，却长期缺乏有效的军队、基础设施和公共服务。
- 有些国家自然资源有限，却能建立强大的财政体系、现代军队和高效行政机构。
- 有些国家经济总量很大，但中央政府难以有效征税、执行政策或提供公共服务。
- 还有些国家能够在战争期间迅速借到巨额资金，却在和平时期维持稳定的公共信用。

这说明一个关键问题：

社会拥有多少财富，与国家能够动员多少资源，是两回事。国家能够动员多少资源，与这些资源最终能转化成多少实际能力，也不是一回事。

我们要研究的不是简单的“国家为什么富”，而是一个更深层的问题：

> 一个社会创造出来的经济剩余，究竟通过什么机制，转化成国家可以持续使用的组织能力？

这涉及财政学、政治经济学、经济史和国家能力理论。

## 一、先建立一个最重要的分析框架

### 第一层：社会创造财富

农业、工业、商业、技术、劳动生产率

形成可以被动员的经济剩余

### 第二层：国家获得资源

税收、国有收入、公共借债、资源租金

取决于征收、信用与组织能力

### 第三层：国家将资源转化为能力

军队、官僚、司法、基础设施、教育、公共卫生

能力反过来影响社会生产力与未来税基

### 第四层：形成反馈循环

有效治理扩大税基；掠夺性汲取侵蚀税基

这个框架可以压缩成三个问题：

1. 有没有财富？——社会生产能力。
2. 国家能不能拿到资源？——财政汲取与公共信用。
3. 拿到资源后能不能有效使用？——组织、技术、执行与监督。

任何一个环节出现问题，都可能让一个富裕社会拥有一个能力不足的国家。

注意，国家能力不是越大越好。一个政府可能很擅长征税、监控和军事动员，却不擅长保护产权、提供司法公正或促进长期生产。我们要研究的是国家能力的具体构成，而不是把“能控制社会”直接等同于“治理得好”。

## 二、第一机制：税基——社会到底创造了多少可持续剩余？

先看一个最简单的模型。

假设两个国家：

| 指标        | 甲国   | 乙国   |
| --------- | ---- | ---- |
| 年度经济产出    | 1000 | 3000 |
| 政府实际获得的资源 | 200  | 150  |
| 政府资源占经济产出 | 20%  | 5%   |

甲国的经济规模只有乙国的三分之一，但政府实际获得的资源更多。

这意味着，乙国虽然更富，却未必有更强的财政动员能力。

这里的数字只是用于解释机制的假设，不是现实国家的数据。

### 1. 什么是税基？

税基不是简单的 GDP，而是能够被税制识别、依法征收并实际收取的经济活动与财富。

例如：

- 农民生产粮食，但没有可靠的土地登记，国家难以准确识别应税土地。
- 商人开展贸易，但大量交易发生在难以监管的网络中，实际税收可能远低于名义税率所暗示的水平。
- 企业利润很高，但通过豁免、优惠、关联交易或跨境安排，实际纳税额可能很低。
- 资源出口产生巨额收入，但收入集中在少数国有企业或政治关联集团手中，未必能转化成稳定、透明的公共财政收入。

因此，可以把实际税收粗略写成：

\\[ T \approx B \times \tau \times c \\]

其中：

- \\(T\\)：实际税收收入；
- \\(B\\)：可识别、可征收的税基；
- \\(\tau\\)：有效税率；
- \\(c\\)：征管实现率，即名义上应收的税款中，最终真正收上来的比例。

这不是完整的税收模型，而是用于拆解机制的近似式。

### 2. 为什么税率高，不一定税收多？

假设税基为 1000：

- 有效税率为 10%，征管实现率为 90%，实际收入约为 90。
- 有效税率提高到 30%，但征管实现率降到 30%，实际收入约为 90。

税率提高了三倍，实际收入却没有增加。

原因可能包括：逃税增加、资本外流、生产活动收缩、征收成本上升，或者有能力的人和企业获得豁免。

所以，国家不能只研究“征多少”，还必须研究：

- 谁在纳税？
- 哪些活动进入正式经济？
- 逃税成本有多高？
- 征收是否公平、稳定、可预期？
- 税收会不会反过来破坏生产活动？

### 3. 为什么现代经济比传统农业社会更容易形成某些税收能力？

现代经济并非天然更容易征税，但它提供了一些传统农业社会缺乏的条件：

- 银行账户和支付系统形成交易记录；
- 企业会计与审计留下可核验的财务信息；
- 工资发放支持源泉扣缴；
- 土地登记、不动产登记和数字化行政系统提高识别能力；
- 大型企业和平台成为可以集中征管的节点。

传统王朝要征农业税，往往需要识别土地、核定户籍、估算产出，再依赖基层官吏执行。现代国家可以利用企业账簿、金融记录和第三方报告来降低部分征管成本。

但数字化也不能消除所有问题：跨国资本、非正规经济、复杂税制、政治豁免和腐败依然可能侵蚀税基。

第一条结论：国家财政的基础，不只是社会有多少财富，还在于财富能否被识别、纳入制度并持续形成公共收入。

## 三、历史案例一：清朝为什么“社会规模扩大，国家财政却没有同比扩大”？

这是一个非常适合检验上述模型的案例。

耶鲁大学法学教授张泰苏在 2020 年发表于《牛津亚洲史研究百科》的研究中指出，清朝在其大部分统治时期，农业税绝对规模相对固定，而人口和经济规模在整个王朝时期接近增长三倍。农业税主要依赖土地持有和农业生产征收。

这里需要区分三个量：

- 社会经济规模：人口、农业产出、商业活动等。
- 国家财政收入：国家实际收到多少资源。
- 国家财政能力：国家能否稳定获得资源，并将其用于治理、军事和公共事务。

如果经济规模持续增长，但主要税源没有相应增长，就会出现一种结构性错配。

### 清代财政的结构性问题

社会经济扩张

人口增加，耕地开发，商业网络扩大，经济活动更加复杂。

主要农业税源增长有限

传统财政制度对农业税的依赖较高，而农业税绝对规模长期变化不大。

财政资源与治理需求可能错配

人口、地方事务和潜在安全压力扩大时，国家可用资源未必同步增长。

### 这为什么重要？

假设一个县原本有 10 万人口，政府能够维持一定数量的基层官员、治安人员和公共事务经费。

后来人口增加到 30 万，但财政资源没有相应增加。

即使官员依旧勤勉，政府也可能面临：

- 每名基层官员需要处理更多人口和案件；
- 水利、治安、救灾等事务需要更多协调；
- 税收纠纷与土地争议更难处理；
- 地方治理越来越依赖乡绅、宗族及其他社会组织。

这并不意味着清朝每个地方都必然出现同样的情况，而是说明：行政覆盖的社会规模扩大，并不自动意味着行政能力同步扩大。

当国家财政资源不足时，社会组织可以帮助承担部分治理任务，但也可能导致国家对地方精英的依赖加深。

### 这里最值得掌握的概念：财政能力的相对萎缩

财政收入即使没有绝对下降，也可能出现相对萎缩。

例如：

- 国家收入增长 10%；
- 需要服务的人口增长 50%；
- 公共事务复杂度进一步提高。

国家未必变得更穷，但它相对于治理任务可能变得更弱。

不过，不能仅凭这一点就推导出“清朝必然灭亡”。晚清危机还涉及太平天国战争、列强军事压力、制度改革困难、地方军事财政权力变化等因素。财政结构是重要背景，不是单独充分的原因。

这个案例揭示的第一条深层规律是：国家能力取决于财政资源与治理任务之间的匹配程度，而不只是经济总量。

## 四、第二机制：汲取能力——国家为什么未必能拿到社会创造的财富？

即使一个社会拥有充足的财富，政府也未必能稳定地把它转化为公共收入。

这与税率高低不同，核心是国家有没有识别、征收和执行的组织能力。

可以将财政汲取拆成四个环节：

1. 识别：知道谁拥有土地、收入、资产或交易。
2. 核定：确定依法应缴多少。
3. 征收：把应缴款项实际收上来。
4. 监督：发现逃税、截留、腐败与选择性执法。

任何一环失效，名义税制都可能无法兑现。

### 1. 中央政府为何会出现“百姓负担重，国库仍缺钱”？

设想一个传统王朝：

- 农户承担土地税、附加征收及其他义务；
- 地方官吏掌握基层信息；
- 大地主或地方权势集团更有能力影响登记、减免和执行；
- 中央无法直接观察每一笔地方征收。

于是可能出现这样的链条：

\\[ \text{百姓实际负担} > \text{中央实际收到的收入} \\]

中间差额可能流向地方经手人、权势集团，也可能消耗在征收和运输过程中，或因欠税、逃亡和执行失败而根本没有被收取。

因此，不能简单认为“农民负担重，就代表国家财政收入高”。

### 2. 为什么中央集权不等于强大的国家能力？

中央集权是一种权力结构；国家能力则是完成任务的能力。

中央可以在制度上拥有最高权威，却仍然缺乏：

- 准确的信息；
- 足够的基层人员；
- 稳定的财政来源；
- 有效的审计系统；
- 可靠的执行链条。

这类似一家大型企业：总部拥有最终决策权，不代表总部能准确知道每个分公司的真实利润，更不代表总部可以无成本地执行所有决策。

所以要区分：

| 概念     | 核心问题         |
| ------ | ------------ |
| 权力集中度  | 谁拥有最终决策权？    |
| 财政汲取能力 | 国家能否持续获得资源？  |
| 行政执行能力 | 政策能否落实到基层？   |
| 信息能力   | 决策者能否获得真实信息？ |
| 监督能力   | 能否发现并纠正执行偏差？ |

这些能力彼此相关，但不能互相替代。

### 3. 现代国家为什么也会出现类似问题？

现代国家拥有数字技术、会计体系和银行网络，仍然可能遇到：

- 大型利益集团影响税制；
- 复杂税收优惠侵蚀税基；
- 腐败导致公共资金流失；
- 政府部门各自掌握信息，难以协同；
- 地方政府执行能力与中央政策目标不匹配。

技术可以降低信息成本，却不能自动消除利益冲突。

第二条规律：国家的法定权力只是潜在能力，只有经过信息、组织、执行和监督，才能转化为实际能力。

## 五、第三机制：公共信用——为什么有些国家能把未来收入变成今天的力量？

这是国家财政史中最重要的机制之一。

假设两个国家都拥有 100 亿的年度财政收入。

- 甲国主要依靠当年征税，当年收多少，主要就花多少。
- 乙国除了征税，还能以较低成本发行长期国债，借助未来税收提前筹集资金。

当战争突然爆发时，两国的能力可能截然不同。

甲国需要立即提高税收、削减其他支出，或者拖欠军饷。

乙国可以先发行国债，立即采购武器、支付军饷，再用未来多年的财政收入偿还债务。

因此，公共信用是一种把未来财政收入转化为当前资源动员能力的机制。

### 1. 国债的本质是什么？

政府发行国债，本质上是：

\\[ \text{今天获得资源} \longleftrightarrow \text{未来偿还本金与利息的承诺} \\]

政府获得资金后，可以立即动员现实资源。但它并没有凭空创造钢铁、粮食、工厂或士兵，而是把未来收入的部分支配权提前承诺给债权人。

这意味着，借债能扩大当前动员能力，却不能无限扩大一个国家的真实资源。

债务可持续性取决于未来财政收入、经济增长、利率、债务期限、币种、市场信心以及政府的财政调整能力。

### 2. 为什么债权人相信某些政府，却不相信另一些政府？

投资者不会只看政府口头承诺，而会判断：

- 政府有没有稳定的未来收入来源？
- 政府是否有能力征税？
- 政府是否有意愿履约？
- 法律是否保护债权人的合同权利？
- 债务是否可能被随意赖掉、重组或通过高通胀稀释？
- 国家是否拥有足够的政治稳定性与偿付能力？

这里存在一个重要区别：

偿付能力是未来是否有足够资源还债；履约意愿与制度可信度是政府是否会按约偿还。

一个国家即使拥有很高的经济产出，如果税收制度薄弱、财政信息不透明、政策随时改变，债权人仍可能要求很高的风险溢价。

### 3. 历史案例：英国如何发展出强大的财政—军事能力？

17 世纪末至 18 世纪，英国逐渐发展出更成熟的公共债务、税收和金融市场体系。1688 年后的制度变化与公共信用发展，是经济史研究的重要议题。

但不能把英国崛起简单归结为“光荣革命后债权人相信政府”这一条因果链。历史研究指出，英国的财政—军事能力还依赖税收制度、议会政治、行政组织、金融网络、海军建设以及国际资源动员。

其核心机制可以概括为：

1. 政府能够获得相对稳定的财政收入。

3. 政府可以发行债务，提前筹集战争所需资源。
4. 金融市场将分散的私人资金汇集为国家可用的融资能力。
5. 国家再将资金转化为舰船、武器、后勤、军队和海外行动能力。

这里有一个值得注意的反直觉现象：一个国家不一定需要在平时就持有全部战争所需的现金，但它必须拥有可信的融资能力和足够可靠的资源动员体系。

2026 年发表在《英国历史评论》上的一项研究进一步强调，1688—1815 年英国的军事动员不仅依赖国内税收和借债，也依赖欧洲金融网络、外国资金与外籍军事人力。英国的国家能力并不是封闭经济体内部独立形成的。

### 4. 为什么高债务不一定意味着弱，低债务也不一定意味着强？

| 情况                | 可能的含义              |
| ----------------- | ------------------ |
| 债务高，但税基稳定、融资成本低   | 可能具备较强的长期融资能力      |
| 债务低，但征税能力弱、基础设施不足 | 可能是动员能力不足，而非财政特别健康 |
| 债务高，且利息支出挤压公共投资   | 财政空间可能持续收缩         |
| 债务低，但严重依赖单一资源收入   | 资源价格下跌时可能迅速出现财政压力  |

所以不能只看债务占 GDP 的比例，还要看债务的用途、成本、期限、币种、偿付来源，以及国家能否在压力下持续融资。

第三条规律：公共信用不是财富本身，而是国家对未来财政能力进行跨期配置的能力。

## 六、第四机制：资源到能力之间，还隔着一整套组织系统

假设一个政府获得了 1000 亿财政收入。

这笔钱能否转化成更强的国家能力，仍然取决于它如何使用。

政府可能将其投入：

- 专业人员和行政系统；
- 教育、公共卫生与基础设施；
- 军事装备、训练与后勤；
- 司法、产权保护和合同执行；
- 科研、技术扩散和产业基础。

也可能因为腐败、项目浪费、采购失灵、维护不足和部门协调失败，导致实际效果远低于支出规模所暗示的水平。

因此：

\\[ \text{财政投入}\neq\text{实际产出} \\]

更完整的分析应当区分三层：

| 层次 | 核心问题      | 示例                 |
| -- | --------- | ------------------ |
| 投入 | 花了多少钱？    | 国防预算、教育支出          |
| 产出 | 实际建成了什么？  | 训练完成的部队、建成的学校      |
| 结果 | 是否产生预期能力？ | 军队战备水平、学习成效、公共健康改善 |

例如，军费增加不一定意味着战斗力同比增长。装备采购、人员训练、指挥体系、后勤、维修和组织协同共同决定最终战斗力。

同样，教育经费增加也不自动等于人力资本提升，关键还在于教师质量、课程设计、管理能力和资源分配。

### 一个容易忽略的经济学问题：国家能力具有互补性

财政能力与法律能力、组织能力之间往往不是简单相加关系。

Besley 和 Persson 在 2009 年发表于《美国经济评论》的研究中，构建了国家能力投资的理论框架，指出财政能力与支持市场的法律能力通常具有互补性。

这意味着：

- 只有征税能力，没有可靠的合同执行，企业可能不愿意长期投资。
- 只有法律文本，没有执行资源，产权保护可能停留在纸面上。
- 只有财政收入，没有专业组织，公共资金也未必能有效转化为公共服务。

可以把国家能力想象成一套相互依赖的系统，而不是一个单一的数字。

## 七、第五机制：资源诅咒——为什么坐拥石油、天然气和矿产的国家，反而可能形成脆弱的财政结构？

这是前面几种机制的集中体现。

资源丰富本身不是问题。真正需要研究的是：资源收入是否替代了国家建设稳定税收制度的动力，以及资源收入由谁控制、如何分配、是否受到有效约束。

### 1. 资源收入为什么与普通税收不同？

假设一个国家有两种收入来源：

- 向企业、劳动者和消费者征税；
- 出口石油，获得资源租金。

如果资源租金足够高，政府就可能在较长时期内不需要从广大社会主体那里获得大量税收。

这可以减轻社会的直接税负，但也可能改变政府与社会之间的激励结构。

当政府主要依赖广泛税收时，它需要建立纳税人登记、财务审计、征收和争议处理系统，并可能受到纳税人对税收使用方式的监督压力。

当政府主要依赖少数资源项目时，它可能只需要控制少数大型矿山、油田或出口节点，就能获得相当可观的收入。

于是，政府有可能缺乏建设广泛税收能力的动力。

2023 年发表于《公共经济学杂志》的一项研究，从理论上分析了资源收入、低税收与弱问责之间可能形成的均衡；2024 年《世界发展》上的跨国研究则指出，资源对财政能力的影响取决于资源类型及政治制度约束，并非所有资源丰富国家都会出现相同结果。

### 2. 用一个简化模型理解

资源租金很高

政府短期内减少对广泛税收的依赖

建立税收行政、公共问责和经济多元化的动力可能下降

资源价格下跌时，财政与治理风险集中暴露

这是一种可能发生的负反馈，并非所有资源型国家都会沿着这条路径发展。

要打破这种风险，关键措施包括：

- 将部分资源收入纳入透明、可审计的财政规则；
- 通过稳定基金或其他财政安排平滑大宗商品价格波动；
- 保留并发展广泛、可持续的税收体系；
- 约束资源收入的任意分配；
- 将资源租金投入能提高未来生产率的领域。

这里还存在一个更深的政治经济学问题：当国家财政不依赖广泛纳税时，政府与社会之间的问责关系可能发生变化。资源收入可以增强国家的财政自主性，却未必增强公共服务和制度建设能力。

第四条规律：自然资源可以直接带来收入，却不会自动带来征税能力、公共信用、专业行政或有效问责。

## 八、把五种机制连接起来：国家能力为什么会形成长期差距？

到这里，我们已经看到五个决定性环节：

1. 税基：社会能够创造多少可持续剩余。
2. 汲取能力：国家能够把多少剩余转化为公共收入。
3. 公共信用：国家能否把未来收入转化为当前动员能力。
4. 组织能力：国家能否把资源转化为真实的治理成果。
5. 制度反馈：国家的行动是在扩大未来税基，还是在侵蚀未来税基。

最重要的一步，是把它们放进一个动态模型中。

### 1. 正反馈：国家能力与社会生产力相互强化

有效司法、稳定产权与公共基础设施

降低交易成本，鼓励投资与专业化分工

生产率和经济活动扩大

税基扩大，财政收入与公共信用增强

进一步投资于行政、教育、基础设施和安全

再投资于国家能力，形成循环

这里的关键不是政府支出越多越好，而是公共资源能够形成足够大的社会回报。

例如，可靠的法院可以降低合同风险；交通设施可以扩大市场范围；教育和公共卫生可以提高劳动生产率。社会生产率提升后，又能为国家提供更稳定的税基。

这构成了国家与社会之间的互补关系。

### 2. 负反馈：国家汲取过度或资源使用低效

公共支出或权力扩张，却缺乏有效监督

税负不确定、寻租增加，公共资金使用效率下降

私人投资、正式经济活动与纳税意愿受到抑制

税基增长放缓，财政压力加大

进一步加税、借债或削减必要的公共投入

若政策继续强化原有问题，负反馈可能持续

这也解释了为什么某些国家会陷入长期低能力均衡。

经济基础薄弱，导致财政收入不足；财政收入不足，导致行政和公共服务难以改善；治理能力不足，又进一步压制生产率与正式经济活动。

但这种均衡不是宿命。税制改革、行政改革、政治联盟变化、技术进步、贸易机会或外部安全环境变化，都可能打破原有路径。

经济学家 Besley、Ilzetzki 和 Persson 在 2013 年发表的研究中，正是通过动态模型分析财政能力投资为何可能走向不同的长期均衡，包括公共服务能力较强的状态与长期弱国家状态。

## 九、国家能力为什么存在路径依赖？

这里再深入一层：为什么两个起点相似的国家，长期发展可能越来越不一样？

因为国家能力不是临时买来的商品，而是需要长期积累的组织资本。

它包括：

- 可持续运行的税务机关；
- 具备专业技能的官僚队伍；
- 可靠的统计与登记体系；
- 能够执行合同的司法机构；
- 可持续的债务管理和公共信用；
- 能够落实预算、采购、建设和维护的行政流程。

这些东西有三个特点。

第一，建设需要时间。 今天增加预算，不等于明天就能拥有成熟的税收征管体系。

第二，存在互补关系。 建立税收系统，需要法律规则、人员培训、数据基础设施和监督机制共同配合。

第三，可能被政治激励削弱。 如果决策者只追求短期收入、政治控制或私人利益，长期能力建设就可能被推迟。

因此，财政收入突然增加，并不一定让国家能力同步增长；财政收入暂时减少，也不一定让一个具有成熟制度的国家立刻失去能力。

一个拥有成熟行政体系和可靠公共信用的国家，可以在短期冲击中维持相当强的动员能力。相反，一个依赖单一收入来源、缺乏行政基础的国家，可能在收入下跌后迅速陷入危机。

## 十、把这套模型用于分析现实国家

如果以后要判断一个国家究竟是“富而强”“富而弱”，还是“暂时富有但长期脆弱”，可以使用下面这张分析表。

| 分析维度 | 关键问题          | 需要观察的证据              |
| ---- | ------------- | -------------------- |
| 生产能力 | 社会能否持续创造经济剩余？ | 劳动生产率、产业结构、经济多元化     |
| 财政汲取 | 国家能否稳定获得收入？   | 税收占 GDP 比重、税收结构、征管效率 |
| 公共信用 | 国家能否以合理成本融资？  | 利息负担、债务期限、融资成本、违约风险  |
| 行政能力 | 资金能否变成真实成果？   | 项目交付、公共服务质量、执行差距     |
| 法律能力 | 能否稳定执行规则与合同？  | 产权保护、司法执行、政策可预期性     |
| 财政韧性 | 冲击发生时能否维持运转？  | 收入来源多样性、储备、债务结构、应急能力 |
| 长期反馈 | 国家行动是否扩大未来税基？ | 公共投资回报、私人投资、生产率变化    |

这里有两个特别容易误判的地方。

一是税收占 GDP 比重高，不自动意味着国家能力强。还要看税制是否可持续、征收是否公平，以及公共资金是否有效使用。

二是财政收入低，也不必然意味着国家能力弱。有些国家的公共职能范围较窄，税负也较低；真正要比较的是其制度目标、财政资源与实际任务是否匹配。

## 十一、最终提炼：国家能力的财政基础，究竟是什么？

可以把整个问题归结为一个概念框架：

\\[ \boxed{ \text{国家能力} = f(\text{税基、汲取、信用、组织、制度反馈}) } \\]

这不是可直接计算国家实力的经验公式，而是一个因果分析框架。

更严格地说：

- 社会生产力决定了国家可以动员的资源上限。
- 财政汲取能力决定了社会资源中有多少能够进入公共财政。
- 公共信用决定了国家能够在多大程度上提前使用未来财政资源。
- 行政与法律能力决定了资源能否转化为真实的治理成果。
- 制度反馈决定上述能力会逐渐增强，还是持续削弱。

还有一个需要始终记住的边界：国家能力不等于国家正当性，也不等于社会福利。一个国家可以非常擅长征税和军事动员，却不一定擅长保护个人权利、改善公共服务或促进广泛繁荣。评价国家能力，必须先明确所说的是哪一种能力。

## 下一步：把模型放回历史中检验

接下来最有价值的研究方向，是第三个问题：

为什么战争经常成为国家能力跃迁的催化剂，却也经常成为国家财政崩溃和政权覆灭的导火索？

它可以把前面两部分连接起来：

- 第一部分解释：地理、战争威胁和社会组织如何影响国家形态。
- 第二部分解释：税收、公共信用和行政体系如何决定国家动员能力。
- 第三部分将进一步解释：战争如何迫使国家建设财政与行政体系，又如何因成本失控、税基破坏和政治冲突而摧毁这些体系。

这将把“国家为什么形成”和“国家为什么强弱分化”推进到一个更完整的历史经济学模型。
