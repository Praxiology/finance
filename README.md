# 从零建立金融学知识体系

本工程以通俗、递进、可检验的方式学习经济学与金融学：从资源约束和选择开始，逐步连接货币、信用、资产定价、宏观周期、国际金融与经济思想史。目标是建立能够独立分析问题的知识体系，不承诺通过阅读文档即可替代系统训练、专业资格或实际经验。

## 学习入口

- [第 003 课：激励机制](课程/第003课-激励机制.md)：规则与收益如何改变行为。

## 如何继续

从 [学习进度与续学记录](学习进度.md) 中的“下一步”开始。每完成一课或一批，就更新进度记录；不要仅凭对话上下文判断学到哪里。建议按课程编号推进，也可以提出某个概念编号要求补课、复习或交叉分析。
