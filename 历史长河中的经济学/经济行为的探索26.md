# 人民币国际化的战略路径：如何在开放、稳定与政策自主之间取得平衡？

我们继续沿着上一节的逻辑往下推。

真正困难的问题不是“中国是否应该开放资本账户”，而是：

如何让人民币逐步成为全球贸易、融资和储值工具，同时避免跨境资本流动反过来冲击国内金融体系，并削弱货币政策的自主性？

这需要把国际金融理论中的三个问题放在一起研究：

1. 货币国际化：让海外企业、银行、投资者和央行愿意使用并持有人民币。
2. 宏观政策自主性：让中国仍然能够根据国内经济情况调整利率、信贷和汇率政策。
3. 金融稳定：防止资本大规模、快速、同向流动，引发资产价格剧烈波动、流动性危机或金融机构资产负债表恶化。

这三者并非完全互相排斥，但也不能假设它们可以不付出任何代价地同时最大化。

## 一、先理解一个基础理论：不可能三角

国际经济学有一个经典框架，称为“不可能三角”（Impossible Trinity），也叫蒙代尔三角。

它认为，一个经济体难以同时完全实现以下三项目标：

- 固定或高度稳定的汇率；
- 资本自由跨境流动；
- 独立的货币政策。

这三个目标为什么存在冲突？

假设中国希望人民币汇率保持相对稳定，同时允许国际资本自由流动。

如果美国利率上升，而中国利率保持不变，国际投资者可能会重新配置资产，将资金从人民币资产转向美元资产。

如果这种流动规模很大，中国就可能面临人民币贬值压力。

为了稳定汇率，央行可能需要调整利率、进行外汇市场操作，或采取其他措施。但这些措施会影响国内信贷条件、经济增长和金融稳定。

反过来，如果中国希望利率完全按照国内经济情况决定，同时保持汇率高度稳定，那么资本流动就不能毫无限制地对利差变化作出反应。

这里的关键是，三角关系讨论的是政策目标与资本流动之间的结构性约束，不是说一个国家只能采用三种固定制度中的某一种，也不是说资本管制可以消除所有金融风险。

现实中，汇率制度、资本流动管理、宏观审慎政策和货币政策可以组合使用，只是各自承担的成本与约束不同。

## 二、真正的制度设计：不要把所有资本流动一视同仁

“不可能三角”解释了宏观约束，但没有直接告诉我们应该怎样设计政策。

更实用的办法是把跨境资本流动拆开，因为不同资金的经济功能、期限和风险差别很大。

例如：

| 资本流动类型      | 主要经济功能          | 需要重点管理的风险          |
| ----------- | --------------- | ------------------ |
| 外商直接投资（FDI） | 建设工厂、引入技术、长期经营  | 资产估值、利润汇回、产业集中     |
| 跨境贸易融资      | 支持出口、进口和供应链周转   | 贸易真实性、期限错配、交易对手违约  |
| 长期债券投资      | 为政府和企业提供长期融资    | 利率变化、信用风险、集中退出     |
| 短期跨境借贷      | 提供流动性与短期资金      | 期限错配、杠杆、突然停止融资     |
| 外汇衍生品交易     | 对冲汇率风险、改善价格发现   | 杠杆、保证金追缴、交易对手风险    |
| 居民及机构跨境资产配置 | 分散投资风险、提高资产配置效率 | 集中购汇、顺周期流动、市场流动性压力 |

这里有一个重要结论：

国际化不等于所有资金在所有时间都可以不受任何约束地自由流动。

但反过来，长期限制所有类型的跨境资金流动，也会压缩国际投资者的参与空间，削弱市场流动性，并降低本币资产的吸引力。

更合理的分析框架，是根据资金用途、期限、杠杆程度和系统性风险，分别设计市场准入、信息披露、风险资本、流动性管理和必要的资本流动管理机制。

IMF 的资本流动政策框架也强调，资本流动可以带来融资、投资和风险分担收益，但在某些情形下也会放大金融风险；资本流动管理措施不应替代必要的宏观经济调整。

## 三、人民币国际化的合理次序：先建立真实需求，再建设金融承载能力

我们可以把人民币国际化拆成四个阶段。它们是一个用于分析政策选择的框架，不是说现实中必须机械地按顺序完成。

### 阶段一

贸易层

扩大人民币在真实贸易中的使用

优先发展有真实贸易背景的人民币计价、结算、贸易融资和企业汇率风险管理。

衡量标准：企业是否因为人民币结算降低了综合交易成本，而不只是因为政策要求使用人民币。

### 阶段二

资产层

扩大人民币资产供给与市场深度

提高政府债券和企业债券市场的透明度、流动性与风险定价能力，完善回购、托管、清算和衍生品市场。

衡量标准：海外持有者是否愿意把人民币收入保留为人民币资产，而不是立即兑换出去。

### 阶段三

融资层

扩大人民币跨境融资与第三方使用

发展境外人民币贷款、债券发行、供应链融资、抵押融资和离岸人民币市场，让人民币不只服务于中国与贸易伙伴之间的双边交易。

衡量标准：海外企业是否能在涉及多个国家的业务中借入、使用、对冲和偿还人民币。

### 阶段四

储备层

提高人民币的长期储值与储备功能

在前三个阶段形成的市场基础上，进一步增强宏观政策的可预测性、资产安全性、兑换机制和金融体系的危机应对能力。

衡量标准：海外央行、金融机构和长期投资者是否愿意持续配置人民币资产，并在市场波动时仍能管理风险。

为什么建议先强化真实贸易需求，再扩大金融市场承载能力？

因为这两者形成互补关系。

没有真实的贸易和融资需求，人民币资产可能缺乏持续的海外使用场景；没有可靠的人民币资产，贸易中积累的人民币又难以沉淀为长期持有需求。

因此，真正可行的路径不是先把结算规模做到最大，再被动补金融市场，而是贸易需求与金融基础设施同步建设，并根据市场承载能力调整开放速度。

## 四、资本账户开放应该先开放什么，后开放什么？

这比笼统讨论“开放还是不开放”更有实际意义。

首先要区分两个方向：

- 资本流入：外国投资者购买中国的股票、债券、企业资产，或向中国企业提供融资。
- 资本流出：中国居民和机构购买海外资产，或向海外提供贷款和投资。

两种方向都很重要。国际货币不仅需要海外主体能够进入人民币市场，也需要中国居民和机构拥有合理的海外资产配置渠道。

如果只允许资金进入而不允许资金在正常规则下退出，投资者会要求更高的风险补偿，甚至不愿进入；如果短期内大规模开放双向流动，而国内金融机构的风险管理能力不足，也可能放大资产价格波动。

因此，可以按照以下原则安排开放的先后次序。

### 1. 先提升规则透明度与市场基础设施

在扩大资金流动之前，先明确投资者准入、资产托管、信息披露、交易结算、违约处置、利润汇回和退出机制。

这一步不一定要求资本流动立即大幅增加，却能减少制度不确定性。

### 2. 扩大与实体经济紧密相关的跨境金融服务

例如真实贸易背景下的人民币贷款、供应链融资、跨境现金管理和企业汇率套期保值。

这类业务能够帮助企业减少币种错配，但仍需要审查贸易真实性、期限错配、关联交易及杠杆风险。

### 3. 深化债券市场与长期投资渠道

扩大合格海外投资者参与，改善债券市场流动性、回购融资、抵押品管理和违约处置机制。

同时，允许境内机构按照透明规则进行多元化的海外资产配置，促进双向资本流动。

### 4. 随着市场承载能力提高，逐步扩大其他资本流动

更广泛的开放需要与汇率弹性、金融监管、银行资本与流动性要求、宏观审慎政策和危机处置机制相协调。

这里并不存在适用于所有国家的唯一开放顺序。关键是每扩大一类资本流动，都要评估它会怎样影响货币政策传导、外汇市场流动性和金融机构资产负债表。

IMF 在 2026 年发布的中国 2025 年第四条磋商报告中，也将汇率弹性、资本流动管理的渐进调整、金融体系风险治理和国内经济再平衡联系起来分析。报告同时指出，资本流动管理措施不应替代必要的宏观经济调整。

## 五、一个经常被忽视的问题：人民币国际化为什么可能要求中国改变自身的经济结构？

这是整个讨论中更深的一层。

假设中国持续拥有很大的贸易顺差，居民储蓄率较高，国内消费相对不足，企业和地方政府又将大量资源投入生产能力扩张。

这种结构可能带来强大的商品供给能力，但也会产生另一种结果：海外市场需要吸收中国持续扩大的净出口，而中国积累的对外净资产也可能不断增加。

如果储蓄持续高于国内投资，便会形成经常账户顺差。

但国际货币国际化的目标，并不只是扩大顺差。人民币需要成为世界愿意持有的资产，这还要求中国国内存在可信赖、可投资、可交易的金融资产，并且海外投资者能够通过稳定的制度安排持有这些资产。

这会引出三个值得研究的结构性问题。

第一，国内需求是否足够强。

如果居民消费、服务业和国内投资机会更加多样化，国内储蓄与投资之间的关系可能发生变化。国际货币地位不要求经常账户必须顺差，也不要求必须逆差；更重要的是国际收支结构是否可持续，以及本币资产是否具有吸引力。

第二，国内金融市场能否提供合理的风险收益组合。

海外投资者不只寻找低风险资产，也需要期限、收益率、信用风险和流动性不同的资产。一个成熟的市场需要允许风险被识别、定价和分散，而不是让所有风险都依赖隐性担保。

第三，生产力增长能否转化为居民收入、企业现金流和可持续的金融回报。

高端制造和 AI 产业即使创造了巨大的技术价值，如果利润长期受到激烈价格竞争侵蚀，或者投资回报不足，相关企业债券和股票的吸引力也会受到影响。

所以，产业升级与金融改革不是两条互不相关的路线。生产力创造的价值，最终需要通过收入分配、企业利润、财政能力和金融市场，转化为可持续的本币资产。

案例三：香港离岸人民币市场——境内外市场可以分层发展

离岸人民币市场提供了一个观察窗口：境外人民币存款、贷款、债券和外汇交易，可以在与境内市场相连接的同时，形成不同的资金供求和价格。

但离岸市场规模也受境外人民币流动性、跨境资金渠道、套期保值成本和市场预期影响。离岸市场可以扩大人民币使用范围，却不能完全替代境内资产市场的深度和制度可信度。

三个案例共同提示：国际货币体系并不是简单地把全球生产力排名映射成货币排名。它是生产力、资产供给、制度安排和历史网络共同演化的结果。

## 七、最终形成一个可用于分析现实政策的框架

我们可以把人民币国际化的政策选择总结为四组相互制约的变量：

| 目标        | 关键政策工具                   | 需要防范的代价           |
| --------- | ------------------------ | ----------------- |
| 扩大国际使用    | 贸易计价、跨境结算、人民币融资          | 只有支付规模增长，缺少长期资产需求 |
| 提升资产吸引力   | 债券市场、回购、衍生品、市场化风险定价      | 资产价格波动、信用损失与杠杆风险  |
| 提高跨境资金流动性 | 逐步开放资本账户、改善兑换和退出机制       | 短期资本流动冲击、资产负债表错配  |
| 保持宏观金融稳定  | 汇率弹性、宏观审慎监管、流动性支持、财政金融协调 | 政策工具之间的冲突与实施成本    |

这不是一张只要按顺序执行就必然成功的路线图，而是一个用来评估每项制度改革的分析框架。

在具体研究中，还需要观察：海外人民币资产持有量、第三方人民币交易、离岸人民币融资成本、外汇对冲市场深度、跨境资金流动的期限结构，以及国内金融机构承受外部冲击的能力。

## 八、把整个理论体系再推进一步

到这里，我们已经把货币国际化与生产力、国际收支、资本账户、金融市场和宏观政策自主性连接起来了。

还剩下一个更加根本的问题：

假设中国在 AI、能源和高端制造领域继续提高全球生产力份额，人民币国际化究竟应该以什么为最终目标？

是追求人民币在全球支付中的占比，还是追求人民币成为海外企业的融资货币、全球资产配置工具，抑或是成为其他国家央行愿意长期持有的储备货币？

这几个目标并不完全相同。它们需要不同的金融市场条件、制度安排和开放程度，也会带来不同的国内政策成本。

下一步最值得深入的方向，是研究国际货币体系的三种权力：

1. 贸易权力：谁能够提供全球经济不可或缺的商品、技术与服务？
2. 金融权力：谁能够提供全球愿意持有、交易和用作抵押品的金融资产？
3. 制度权力：谁的货币规则、金融基础设施和危机应对机制能够被其他经济体持续采用？

这三种权力可能集中在同一个国家，也可能分散在不同国家之间。

它们之间的关系，将帮助我们进一步理解：即使未来全球生产力格局发生重大变化，国际货币体系为什么仍可能长期保持多层次结构，以及人民币可能通过哪些不同路径扩大自身的国际作用。
